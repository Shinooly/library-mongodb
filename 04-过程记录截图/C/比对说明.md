## 二、聚合查询：Compass 图形化结果与命令行结果比对

在 Compass 中对 `books` 集合执行 Aggregations，管道（两个阶段 `$group` → `$sort`）：

```javascript
[
  { "$group": {
      "_id": "$category",
      "total_stock": { "$sum": "$stock" },
      "avg_price": { "$avg": "$price" },
      "avg_rating": { "$avg": "$rating" },
      "book_count": { "$sum": 1 }
  } },
  { "$sort": { "total_stock": -1 } }
]
```

命令行等价语句：

```javascript
db.books.aggregate([{$group:{_id:"$category",total_stock:{$sum:"$stock"},
  avg_price:{$avg:"$price"},avg_rating:{$avg:"$rating"},book_count:{$sum:1}}},
  {$sort:{total_stock:-1}}]).toArray()
```

两边都返回 **6 条**，逐行比对如下（Compass / 命令行 / `category_stats.json` 三处数值完全相同）：

| 类别 | 藏书量 | 平均价格 | 平均评分 | 书目数 |
|---|---|---|---|---|
| 文学 | 181 | 47.01666666666667 | 4.625 | 12 |
| 计算机 | 172 | 89.53333333333333 | 4.533333333333333 | 15 |
| 数学 | 122 | 40.666666666666664 | 4.433333333333334 | 6 |
| 外语 | 72 | 59 | 4.32 | 5 |
| 经济管理 | 64 | 90.85714285714286 | 4.3 | 7 |
| 历史 | 50 | 95.6 | 4.66 | 5 |

排序也一致：按 `total_stock` 降序，文学 181 > 计算机 172 > 数学 122 > 外语 72 > 经济管理 64 > 历史 50。

## 三、统计结果导出

`category_stats.json` 由程序菜单 12（`StatManager.export_category_stats`）导出，共 6 条，
字段为 `category` / `total_stock` / `avg_price` / `avg_rating` / `book_count`，
按藏书量降序，与上表逐行一致。

> 导出时修复了一个缺陷：`category_stats` 的分类名保存在 `_id` 中，
> 原实现 `find({}, {"_id": 0})` 会把分类名丢掉，导出的文件只剩数字。
> 现改为用 `$project` 把 `_id` 改名为 `category` 并置于结果中（`library-platform/app/stat_manager.py`）。

## 四、验收结论

1. Compass 能正常连接 `127.0.0.1:27017`，五个集合的文档量与命令行一致（50 / 30 / 3000 / 6 / 0）。
2. 同一条聚合管道在图形界面与命令行得到完全相同的 6 条结果，字段值与排序均一致。
3. `category_stats.json` 已导出，内容与界面、命令行结果一致，可作为交付物。
